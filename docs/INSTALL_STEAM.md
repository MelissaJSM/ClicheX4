# Steam 설치와 복원

대상은 **Mega Man X Legacy Collection 1**, App ID `743890`, 검증 Build ID `21253628`입니다. Windows 11에서 검증했습니다. 컬렉션 2용 패치가 아닙니다.

지원 `RXC1.exe` SHA-256: `8c549623ce4f010ee0b3c23b17fe1ea52d3bc2acfcac9be9b0ecf374cfaa6949`

1. 게임을 종료하고 Releases의 `ClicheX4_Steam_v1.0.3_GitHub.zip`을 새 폴더에 모두 풉니다.
2. `ClicheX4.exe`를 실행합니다. `_internal`, `patches.zip`을 함께 보관하세요.
3. RXC1.exe가 있는 게임 폴더를 확인하고 **패치 설치**를 누릅니다.
4. Steam 로그인 상태에서 **모드 실행**을 누르고 실행 보정 완료를 기다립니다.
5. X4의 `Change game edition`으로 판을 바꿉니다. 기본 키보드 설정은 X입니다. English (US)는 시부키/리코, Japanese는 나나/린입니다.

**다음 실행도 전용 실행기의 모드 실행을 사용합니다.** Steam 직접 실행만으로는 필요한 실행 보정이 모두 들어가지 않습니다. 실행 보정이 끝나면 실행기를 닫아도 됩니다.

원본 자원은 게임 폴더의 `.clichex4/original`에 백업됩니다. 이를 삭제하거나 다른 버전의 백업으로 덮어쓰지 마세요. 원본 복원은 게임 종료 후 실행기의 **원본 복원**으로 수행합니다. RXC1.exe·Steam 저장 파일·config.ini는 패처가 수정하지 않습니다. 게임 자체는 실행·저장 과정에서 저장 데이터를 갱신할 수 있습니다.

기존 배포 v1.0.0~v1.0.2에서 바로 업데이트할 수 있습니다. `GitHub` 패키지는 v1.0.3 실행 파일과 패치를 그대로 유지하고 공개용 권리 안내와 문서를 보강한 포장입니다. 게임 변경 사항을 추가하지 않았습니다.

Steam 업데이트나 파일 무결성 검사는 변경 자원을 원래대로 되돌릴 수 있습니다. 지원 해시가 다르면 강제 설치하지 않습니다. 설치기는 다른 수정본을 덮어쓰는 범용 병합 도구가 아닙니다.

FMV와 영상 음성, 컬렉션 전체 언어는 교체하지 않습니다. Steam과 PS1의 저장을 변환하는 기능도 없습니다.

스텔라이브 관련 콘텐츠의 권리는 스텔라이브 및 각 권리자에게 있으며 요청 시 삭제될 수 있습니다. 원작 게임의 저작권과 소유권은 CAPCOM에 있습니다. [전체 고지](../NOTICE.md)
