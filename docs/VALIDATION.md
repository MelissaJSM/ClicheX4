# 검증 범위

## 이번 공개 자료 준비

- 두 PS1 차이 패치를 지원 원본에 적용하여 현재 완성 BIN과 SHA-256이 정확히 일치함을 확인했습니다.
- PS1 패처의 잘못된 원본·손상 패치·기존 출력·입출력 충돌·부적절한 출력 이름 거부와 원본 보존을 검사했습니다.
- 동봉 Windows 실행 파일로 두 실제 패치의 전체 복원 해시를 다시 검사했습니다.
- 최신 두 BIN에서 스프라이트·인덱스 레이어·일러스트를 새로 추출했습니다. 입력 해시, 프레임 해시, 조립·원점·팔레트와 제외 목록을 기록했습니다.
- 대표 이미지와 네 소개판을 브라우저로 렌더링한 뒤 글자, 그림, 무기 연결, 색상 및 배치를 확인했습니다. 새 그림으로 실제 자산을 대체하지 않았습니다.
- 저장소 파일의 원본 게임/BIOS/저장 파일/개인 경로 포함 여부, 문서·이미지 경로와 코드 구문을 검사합니다. 최종 목록 및 결과는 `publication-audit.json`을 참고하세요.

## 기존 완성본의 검증

PS1 최신화는 두 모드의 2,928개 그래픽 참조와 8,852개 조립 프레임을 Steam과 대조했습니다. 누락된 시부키 오드아이를 344프레임에서 대조했고 원본 압축 해제·HQ 상태·비대상·섹터 EDC/ECC 보존을 검사했습니다. 사용자가 최신 PS1의 적용을 확인했습니다.

Steam v1.0.3은 설치·재설치·검사·복원, v1.0.0~v1.0.2 업데이트, 최종 ZIP 독립 실행을 검사했습니다. 지원 원본 237자원을 다루고 실행 파일 자체를 수정하지 않습니다. 캐릭터 선택·인게임 주요 동작·일러스트·사운드·낙하 얼음·최신 컬렉션 그림 등은 제작 중 사용자 확인을 받았습니다.

## 제한

- 모든 장비 조합·방향·스테이지·엔딩을 모든 환경에서 전수 실기 검증했다는 뜻은 아닙니다.
- 이번 작업은 공개 자료와 패처 준비이며 게임 전체를 다시 플레이한 검증은 아닙니다.
- 정적 PNG·그림 합성·Unicorn 검사와 실제 에뮬레이터/Steam 플레이를 구분합니다.
- 다른 Steam 빌드, 다른 PS1 리비전, 모든 에뮬레이터와 PS1 실기의 호환성은 보장하지 않습니다.
- 오래된 세이브스테이트가 이전 자원·코드를 유지할 수 있습니다. 새 CUE 부팅과 메모리카드 불러오기로 확인하세요.

버그 제보를 받으면 재현 조건과 변경 범위를 기록하고, 기존 수용본을 보존한 채 수정합니다.
